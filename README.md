## RPG GAME - New MOBS, JSON, GIT

This time im doing my biggest project(for now!), it's a RPG with more bosses, shop, items, and progression save. 
Currently running on terminal but i promissed a will learn to create a visual game. 

## How to play?

Run 'python main.py'
Choose between New Game or Load Game at the start.
Each turn, choose your action:

[1] Attack 
[2] Items 
[3] Shop

## Save System

With JSON, after killing an enemy your progress is saved, you can LOAD your progress at the start of the game, with [2] LOAD GAME.
